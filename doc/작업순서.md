1. 화면 범위 확인
Figma에서 필요한 페이지와 프레임을 확인합니다. 데스크톱·모바일 화면, 주요 상태, 버튼을 눌렀을 때의 변화까지 살펴봅니다.

2. 디자인 값 수집
프레임 크기와 간격, 색상, 글꼴·크기·굵기, 모서리 값을 기록합니다. 로고와 아이콘은 가능하면 SVG로, 사진은 목적에 맞는 크기와 형식으로 내보냅니다.

3. 화면을 영역과 상태로 나누기
공통 헤더, 메뉴, 보드, 점수 영역처럼 구조를 나누고, 게임 전·진행 중·승패 결과·재시작 대화상자처럼 상태도 구분합니다.

4. 의미 있는 마크업 작성
이 프로젝트에서는 index.pug가 페이지 원본입니다. 제목과 버튼의 의미를 HTML 구조로 표현하고, 재사용할 시각 요소에는 c- 컴포넌트 이름을, 배치에는 l- 레이아웃 클래스를 사용합니다.

5. 스타일 구현
디자인 토큰은 _variables.scss에 정리하고, 공통 스타일과 페이지 전용 스타일을 분리합니다. 모바일 화면을 먼저 맞춘 뒤 넓은 화면으로 확장하고, Figma의 간격·타이포그래피·색상과 실제 화면을 비교합니다.

6. 상호작용과 접근성 처리
게임 동작은 main.js에 구현합니다. 키보드 조작, 포커스 표시, 이미지 대체 텍스트, 상태 변경 알림도 함께 확인합니다.

7. 빌드하고 화면 비교
npm run build로 결과물을 만들고, npm run dev로 브라우저에서 확인합니다. 모바일·태블릿·데스크톱 크기에서 화면을 비교해 넘침이나 어긋남을 고친 뒤 다시 확인합니다.
